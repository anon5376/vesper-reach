# Yielding Spare Usage

## Overview

Spare usage buys one thing a stranger would keep. A second idea is one line, not a build.

**Violating the letter is violating the spirit.**

## When to Use

A reset is coming and nothing urgent is queued. The user says spare, leftover, unused, or not to waste it. A README tidy, old plan, familiar demo, or waiting question is about to take the window.

Skip this when the user already named the task, or asked to conserve quota, schedule a backlog, or sell unused credits.

## The record

`YIELD.md` beside the artifact. Heading, blank line, six lines, nothing else.

```
# Yield

Spare: included usage resets tonight
Job: one page that files a single field note on this machine
Nearest neighbor: a notes app, whose job is to keep many notes
Graft: none
Proof: `node --test` → # fail 0
Left on the table: tags on the note
```

Copying that Job fails the checker. Do not copy the examples.

```bash
node check-yield.mjs --root <yield-dir> [--graft-root <project-dir>]
```

Run that from this skill's directory. `--graft-root` is required when Graft is not `none`. Stop at `yield ok`.

## Graft

`none`, unless the yield needs a file that existed before this window. Sanding nouns off its loop makes it the neighbor.

## Order

1. Write the six lines. The Proof command fails before the artifact exists.
2. Cover one finished path and one wrong path. Paste the pass or fail line, not a timer. Leave files that were already there.
3. Run the checker. Leave Left on the table unbuilt.

## Rationalizations

| Excuse | Reality |
| --- | --- |
| "It would be a shame to waste that plan" | An unprovable plan is not the yield. |
| "Just tidy a README so we don't look like we're gold-plating" | A README of a hole describes the hole. |
| "A chase camera would have looked more like a game" | A picture is not a finished path. |
| "The smart move is a polished todo app or a habit tracker" | That demo is the neighbor. |
| "Don't waste the sketch" | A sketch is not a requirement. |
| "Base it on the other project so the spare feels used" | Sanded-off nouns are the neighbor. |
| "The reasoning is in the chat" | The chat ends. The six lines stay. |
| "The README tells them how to run it" | A how-to is not a result. |
| "I'll ask before spending the window" | Waiting spends the spare. |
| "The smallest command that exits 0 is enough" | One printed number is not a yield. |

## Red flags

Plan or README as the only file. Two products. Deleting files that were already there. One printed number. A graft file this window created. Proof that says not run, would, or later. A question that waits out the reset.
